USE YOUR OWN PROJECT SCREENSHOTS (optional)
==========================================

The site currently uses professional stock previews from Unsplash.

To use YOUR real project images:

1. Save screenshots in this folder, for example:
   - oluwasegun-clothing-hub.jpg  (your live store — already added)
   - ecommerce.jpg
   - funnel.jpg
   - portfolio.jpg

2. Open src/data/projects.ts and change each image to:
   image: "/projects/ecommerce.jpg",

3. Restart: npm run dev

Tip: Use 1200px wide JPG or WebP for fast loading.
